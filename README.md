# IMDb-Data-Mining
בפרויקט זה בניתי מאגר נתונים (Dataset) של 5,000 סרטים פופולריים שמתחילים באותיות W ו-X. המאגר משלב נתונים רשמיים מ-IMDb (דירוגים, שנים, ז'אנרים) יחד עם מידע פיננסי (תקציב והכנסות) ותקצירים שנאספו מוויקיפדיה.

שיטת איסוף הנתונים
הנתונים נאספו בשני שלבים:

שלב IMDb: טעינת קבצי TSV גדולים, סינון לסרטים בלבד ומיון לפי הפופולריות שלהם (כמות הצבעות).

שלב Wikipedia: עבור כל סרט, הקוד ניגש לוויקיפדיה, אימת את שנת הסרט, ושלף מהטבלה ("Infobox") את התקציב וההכנסות. בנוסף, הקוד שלף את פסקאות התקציר (Plot) של הסרט.

עיבוד כספי: נתוני התקציב וההכנסות נוקו מטקסט והומרו למספרים המייצגים מיליוני דולרים (כולל חישוב ממוצע במקרה של טווחי מחירים).

הוראות הרצה (איך להפעיל את הפרויקט)
כדי שהקוד יעבוד במחשב אחר, יש לוודא את הדברים הבאים:

התקנת ספריות: יש להתקין את הספריות בעזרת הפקודה: pip install pandas requests beautifulsoup4.

קבצי נתונים: יש לשים את הקבצים המקוריים של IMDb (שמסתיימים ב-.tsv.gz) בתוך תיקייה בשם data.

הרצה: יש לפתוח את הקובץ notebook.ipynb ולהריץ את כל התאים לפי הסדר.

מבנה קבצי הפרויקט
notebook.ipynb - קוד הפייתון המלא של הפרויקט.

dataset.csv - קובץ הנתונים הסופי והמעובד.

report.pdf - דוח ניתוח הנתונים והחלטות הנדסיות.

README.md - קובץ זה (הסברים והוראות).
